Create a checkout session

Creates a session for a customer to pay for line items. Amounts are in the smallest currency unit (paise for INR).

const session = await payments.checkout.create({
  currency: "inr",
  line_items: cart.map((i) => ({
    price: i.variant.price * 100,
    quantity: i.qty,
  })),
  success_url: "https://shop.local/thanks",
});

Parameters

currencyrequired · three-letter ISO code
line_itemsrequired · up to 100 items
success_urlrequired · redirect after payment
couponoptional · applies a discount
